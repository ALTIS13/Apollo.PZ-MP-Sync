# Apollo MP Sync client installation

## 1. Subscribe

Open [Apollo MP Sync in Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3780069702) and select **Subscribe**. The Workshop item is `3780069702` and the Mod ID is `ApolloMPSyncB42`.

## 2. Enable

Start Project Zomboid `42.20.2`, open **Mods**, and enable **Apollo MP Sync [B42.20.2]** if the server does not enable it automatically.

## 3. Connect

Join the multiplayer server normally. If the server distributes its required Workshop items, allow Steam to finish the download before reconnecting.

Clients never install Java. Clients never install Native Assist or the administrator installer. This release supports Project Zomboid `42.20.2` only.
