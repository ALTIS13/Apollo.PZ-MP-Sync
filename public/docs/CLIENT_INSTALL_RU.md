# Установка Apollo MP Sync для клиента

## 1. Подписка

Откройте [Apollo MP Sync в Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3780069702) и нажмите **Подписаться**. ID предмета Workshop — `3780069702`, Mod ID — `ApolloMPSyncB42`.

## 2. Включение

Запустите Project Zomboid `42.20.2`, откройте **Моды** и включите **Apollo MP Sync [B42.20.2]**, если сервер не сделал это автоматически.

## 3. Подключение

Подключитесь к многопользовательскому серверу обычным способом. Если сервер распространяет обязательные предметы Workshop, дождитесь окончания загрузки в Steam и подключитесь снова.

Клиенты не устанавливают Java. Клиенты не устанавливают Native Assist или администраторский установщик. Этот выпуск поддерживает только Project Zomboid `42.20.2`.
